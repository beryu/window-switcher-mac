# Window Switcher
![desktop](assets/desktop.png)
It's experiment app for trying Accessibility API.

## Usage

### Window Switcher
1. Press Control + Escape to show Window Switcher
2. Press an alphabet that you want to focus

### UI Element Selection
1. Press Option + Escape to show UI Element Selection
2. Type the alphabet displayed on the element you want to click

### Scroll Mode
1. Press Control + Option + Escape to start Scroll Mode
2. Select a scrollable area if multiple exist
3. Use `h`, `j`, `k`, `l` keys to scroll

## Requirements

- macOS 14.0+
